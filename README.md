# Call-center-Trends
Call Center Trends Dashboard

Project Overview

Interactive Power BI dashboard analyzing call center data, providing insights into agent performance, resolution rates, and customer satisfaction.

Key Features

- Average Satisfaction Rating Gauge
- Answered and Resolved Donut Charts
- Average Speed of Answer KPI
- Number of Calls per Month Stacked Column Chart
- Agent Statistics Table
- Interactive slicers for Agent, Resolved, and Year

Technical Specifications

- Built with: Power BI, Excel
- Data Visualization: Gauge, Donut, Stacked Column charts
- Data Analysis: Data modeling, DAX formulas

- Improved agent performance tracking and evaluation
- Developed scalable and interactive dashboard
